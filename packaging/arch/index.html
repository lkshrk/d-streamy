D-Streamy pacman repository

Signed Arch Linux packages of D-Streamy @VERSION@: dstreamy for x86_64 and aarch64, and the OBS plugin obs-dstreamy for x86_64.

The packages are signed with the key @FINGERPRINT@. Import it and sign it locally:

curl -fsSLO https://lkshrk.github.io/d-streamy/arch/d-streamy.asc
sudo pacman-key --add d-streamy.asc
sudo pacman-key --lsign-key @FINGERPRINT@

Add the repository to /etc/pacman.conf:

[d-streamy]
Server = https://lkshrk.github.io/d-streamy/arch/$arch

Then install:

sudo pacman -Syu dstreamy obs-dstreamy

Each release replaces the repository; only the current version is available.
